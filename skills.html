Skills

These are the technical and professional skills I am developing.

HTML

Semantic HTML
Using meaningful HTML elements, such as header, nav, main, and article, to structure web pages in a way that reflects their actual content and purpose, rather than relying on generic containers. This makes pages easier to read, maintain, and navigate for both people and assistive technologies.
Forms
Creating forms with properly associated labels, appropriate input types, and built-in validation, so that users can enter information accurately and receive clear feedback when something is missing or incorrect, rather than a form that just fails silently on submission.
Tables
Organising and presenting tabular data using proper table structure, including headers, captions, and scope attributes, so that information like schedules or comparisons is easy to scan visually and makes sense when read by a screen reader.

C Programming

C
Learned the fundamentals of C programming, including how to declare and work with variables and data types, use operators to perform calculations and comparisons, and structure a program's logic using control structures that decide what the program does at each step.
Loops
Comfortable using if/else statements and switch cases to handle different conditions, along with loops such as for, while, and do while, to repeat actions and process input until a particular condition is met, which is central to writing programs that respond sensibly to different situations.

CSS

Styling
Using CSS to control layout, colours, spacing, and typography, with an emphasis on keeping styles consistent across an entire site through reusable values rather than repeating the same choices page by page.
Responsive Design
Creating layouts that adapt to different screen sizes using tools like Flexbox, CSS Grid, and media queries, so that a page remains easy to read and navigate whether it's viewed on a phone, tablet, or desktop screen.
