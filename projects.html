Projects

A collection of projects completed during my learning journey.

Basic calculator

Developed a command-line calculator in C that performs the four basic arithmetic operations: addition, subtraction, multiplication, and division. The program asks the user to enter two numbers and choose an operation, then works out which calculation to run and displays the result back to them. A key focus of this project was organising the program into separate, well-defined functions rather than writing everything in one place, which made the code easier to read, test, and build on. It also includes basic error handling, such as checking for division by zero, so the program responds sensibly to invalid input instead of crashing. Building this project helped strengthen my understanding of how programs store and work with data, how decision-making structures like switch statements and loops control a program's logic, and how to break a problem down into smaller, manageable pieces, a habit that carries over directly into how I approach web development.

Concepts Used

  • Variables and Data types
  • User input and output (scanf/printf)
  • Functions
  • Switch statements
  • Loops

Survey Form

An HTML form designed to collect information from users, built to practice creating accessible and well-structured forms from scratch. The form gathers a mix of information using different input types, including text fields, radio buttons for single-choice questions, and checkboxes for questions where multiple answers could apply. Every input is properly paired with a label, and required fields include built-in validation so users get immediate feedback if something is missing or entered incorrectly, rather than submitting the form and finding out later. This project helped me understand how to think about forms from the user's perspective, not just how to mark them up correctly in HTML. It taught me the importance of clear labelling, sensible input types, and validation that guides people toward completing a form successfully instead of just blocking them when something goes wrong.

Concepts Used

  • Labels and inputs
  • Radio buttons
  • Checkboxes
  • Form validation

Personal Portfolio Website

Designed and developed a personal portfolio website to showcase my education, skills, projects, and experience. Built using HTML and CSS with a focus on creating a clean, responsive, and user-friendly layout. The site is structured as a multi-page layout with a consistent header, navigation, and footer across every page, making it easy for visitors to move between sections such as education, skills, and projects. I used semantic HTML throughout to keep the structure meaningful and accessible, paired with Flexbox and CSS Grid to arrange content like the navigation bar, skill cards, and project cards in a way that adapts cleanly to different screen sizes. This project brought together everything I had learned up to this point into one cohesive piece of work, and gave me practical experience planning a website's structure from scratch, organising content across multiple pages, and refining the visual design so it feels consistent and professional rather than like a collection of separate exercises.

Concepts Used

  • Semantic HTML
  • CSS Grid
  • Flexbox
  • Responsive design
